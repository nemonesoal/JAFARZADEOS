# JAFARZADEOS 1.1 — سورس سیستم Live قابل بوت

این پروژه یک سیستم Live واقعی مبتنی بر Debian 12 (Bookworm) و XFCE برای رایانه‌های x86_64 است. پس از ساخت ISO، کامپیوتر مقصد برای بوت و اجرا به ویندوز یا سیستم‌عامل دیگری احتیاج ندارد. این ZIP سورس و پیکربندی ساخت است؛ ISO آماده داخل آن نیست.

## امکانات پیکربندی‌شده
- دسکتاپ XFCE با تم تیره، تصویر پس‌زمینه و پنل پایین با منوی برنامه‌ها، فهرست پنجره‌ها، سینی سیستم، صدا، ساعت و خاموش‌سازی
- میانبرهای دسکتاپ برای مرورگر، Writer، Calc، Impress، My PC، ویرایشگر کد، ماشین‌حساب، ترمینال و Control Center
- Thunar برای فایل‌ها و درایوهای واقعی متصل
- Firefox ESR
- LibreOffice Writer / Calc / Impress
- Geany، Git، Python 3 و ابزارهای پایه توسعه
- NetworkManager، ابزار Wi-Fi، Bluetooth و firmwareهای رایج
- مرکز کنترل گرافیکی با میانبرهای تنظیم نمایشگر، ظاهر، صفحه‌کلید، ماوس، صدا، شبکه، بلوتوث و انرژی
- ابزارهای صدا، روشنایی، مدیریت انرژی و تنظیمات نمایشگر
- فونت‌های Noto و فارسی
- بوت Live با پارامتر persistence

## ساخت از روی ویندوز ۷ نسخه ۶۴ بیتی
خود ویندوز ۷ ابزار ساخت Debian Live را اجرا نمی‌کند. راه پیشنهادی ساخت داخل ماشین مجازی Debian 12 amd64 است.
1. مطمئن شو پردازنده ۶۴ بیتی و قابلیت مجازی‌سازی Intel VT-x یا AMD-V فعال است.
2. VirtualBox 6.1 سازگار با Windows 7 را نصب کن.
3. یک VM با Debian 12 amd64 بساز؛ حداقل 4GB RAM (بهتر 6GB)، دو هسته CPU و دیسک مجازی پویا حداقل 40GB.
4. Debian را نصب کن و اینترنت VM را فعال کن.
5. ZIP را داخل Debian منتقل و استخراج کن.
6. ترمینال را در پوشه پروژه باز کن و اجرا کن: `sudo ./build.sh`
7. پس از پایان، فایل ISO در همان پوشه پروژه ساخته می‌شود. ساخت به اینترنت و چندین گیگابایت فضای خالی نیاز دارد.
8. فایل ISO را با Shared Folder یا USB به ویندوز منتقل کن.

## ساخت فلش بوتیبل
با Rufus یا balenaEtcher فایل ISO را روی فلش بنویس. این کار اطلاعات فلش مقصد را پاک می‌کند. ابتدا در ماشین مجازی و سپس روی یک کامپیوتر واقعی آزمایش کن.

## ماندگاری اطلاعات
پارامتر `persistence` فعال شده، اما به‌تنهایی فضای ماندگار ایجاد نمی‌کند. برای persistence واقعی باید یک پارتیشن جداگانه ext4 با برچسب دقیق `persistence` بسازی و در ریشه آن فایل `persistence.conf` با محتوای زیر قرار دهی: `/ union`
ایجاد یا تغییر پارتیشن ممکن است اطلاعات را پاک کند؛ قبل از آن از فایل‌ها نسخه پشتیبان بگیر. ماندگاری را با ایجاد فایل آزمایشی، خاموش کردن کامل و بوت مجدد بررسی کن.

## محدودیت‌ها و شفافیت
- این نسخه یک محیط دسکتاپ لینوکسی سفارشی‌شده است، نه کپی ویندوز و نه هسته‌ای مستقل که از صفر نوشته شده باشد.
- پنل XFCE و ابزارهای تنظیمات واقعی هستند؛ ظاهر و چیدمان ممکن است با نسخه/رزولوشن نمایشگر کمی فرق کند.
- تنظیم روشنایی، Wi-Fi، صدا، بلوتوث و خاموش‌سازی به درایور و سخت‌افزار وابسته است.
- پارامتر splash برای صفحه شروع گرافیکی فعال شده؛ ظاهر نهایی Plymouth و نمایش لوگوی اختصاصی باید روی ISO ساخته‌شده بررسی و تکمیل شود.
- پشتیبانی Secure Boot و BIOS/UEFI باید روی دستگاه مقصد تست شود.
- ظرفیت ۱۶ گیگابایت برای سیستم + مجموعه آفیس + persistence محدود است. فلش ۳۲ گیگابایت برای استفاده عملی راحت‌تر است.
- این پروژه هنوز ISO ساخته و روی سخت‌افزارهای مختلف آزمایش نشده است؛ هیچ سازگاری سخت‌افزاری را بدون تست نمی‌توان تضمین کرد.
